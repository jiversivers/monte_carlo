photon_canon.hardware.cone_of_acceptance(x, y, mu_z=None, na=1.0, n=1.33, r=0.16443276801785273)

Detector function that accepts photons based on angle and radial distance.

Accepts photons within a specified numerical aperture and radial extent.

Parameters:

  • x (Union[Real, Iterable[Real]]) – x-coordinate(s) of the photon.

  • y (Union[Real, Iterable[Real]]) – y-coordinate(s) of the photon.

  • mu_z (Union[Real, Iterable[Real]]) – z-direction cosine(s) for angular filtering.

  • na (float) – Numerical aperture.

  • n (float) – Refractive index of the medium.

  • r (float) – Maximum radial acceptance.

Returns:

Boolean mask indicating which photons are accepted.

Return type:

NDArray[bool]
