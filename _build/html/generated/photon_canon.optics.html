class photon_canon.optics.Detector(acceptor=functools.partial(<function cone_of_acceptance>, r=0.16443276801785273, na=1.0, n=1.33), desc=None)

Bases: object

Simple tally detector that counts photons accepted by a user-supplied acceptance function.

The detector maintains two running counters:

  • n_total – total weight of photons presented.

  • n_detected – weight of photons whose exit positions and directions satisfy the acceptance criterion.

Parameters:

  • acceptor (Callable[[numpy.ndarray, numpy.ndarray], numpy.ndarray]) –

    Callable that decides if a photon hits the detector. It is called as acceptor(x, y, mu_z=mu_z) where

    • x, y – exit coordinates of each photon (mm),

    • mu_z – := cos(θ_exit) (z-component of direction).

    Must return a Boolean array of the same length. The default is an aperture defined by create_cone_of_acceptance().

  • desc (str | None) – Optional description string.

Variables:

  • n_total – Cumulative weight of all photons processed.

  • n_detected – Cumulative weight of photons accepted.

  • acceptor – Acceptance function provided at construction.

  • description – Raw description string.

Raises:

ValueError – If __call__() is invoked with an object that is not a Photon.

Usage example

>>> det = Detector(desc="f/2.4 collection cone")
>>> det(photon_packet)          # tally all photons in the packet
>>> det.n_detected / det.n_total   # detection efficiency
0.031

NumPy ndarray subclass that renormalises itself whenever its values change.

The object behaves like a normal array but keeps an internal flag (normalize) that, when True, forces the vector(s) to be scaled to unit length after every assignment.

Parameters:

  • arr (Iterable) – Initial data used to construct the array.

  • normalize (bool, default False) – If True, the array is normalised to unit length on creation and after every in-place update.

  • dtype (numpy.dtype | None) – NumPy data type to cast arr to. If None, the dtype is inferred by numpy.asarray().

Returns:

A view of arr as an IndexableProperty.

Return type:

IndexableProperty

Variables:

normalize (bool) –

Read/write property controlling automatic normalisation. Setting

>>> vec.normalize = True

retroactively rescales the current data.

Notes

  • Normalisation is performed along the last axis:

    \[\mathbf{x} \leftarrow\]

rac{mathbf{x}}{lVert mathbf{x} Vert_2}

  • When slicing, the returned view disables auto-normalisation so that scalar assignments do not accidentally rescale the parent array.

Examples

list(v)                  # [0.0, 1.0]

row = v[:]               # slice → normal ndarray behaviour
row[1] = 10
list(v)                  # still [0.0, 1.0]

class photon_canon.optics.Medium(**data)

Bases: BaseModel

Container for the optical properties of a homogeneous layer (\(n, \mu_s, \mu_a, g\)) optionally specified as functions of wavelength.

Parameters:

  • n (float) – Refractive index of the medium.

  • mu_s (float | numpy.ndarray) – Scattering coefficient \(\mu_s(\lambda)\,[\mathrm{mm}^{-1}]\) (scalar or numpy.ndarray).

  • mu_a (float | numpy.ndarray) – Absorption coefficient \(\mu_a(\lambda)\,[\mathrm{mm}^{-1}]\) (scalar or numpy.ndarray).

  • wavelengths (numpy.ndarray) – Wavelength grid (nm) that matches any array inputs. Defaults to the module-level wl variable.

  • ref_wavelength (float) – Reference wavelength (nm) used by correction utilities.

  • g (float) – Scattering anisotropy factor (\(-1 \le g \le 1\)).

  • desc (str) – Human-readable description for __str__/__repr__.

  • display_color (str | None) – Hex/CSS colour to use when plotting.

Raises:

AssertionError – If mu_s or mu_a contains negative elements, or if g lies outside \([-1, 1]\).

Computed attributes

Variables:

  • mu_t –

    Total attenuation coefficient

    \[\mu_t(\lambda) \;=\; \mu_s(\lambda)\;+\;\mu_a(\lambda)\]

  • albedo –

    Single-scattering albedo

    \[a(\lambda) \;=\; \frac{\mu_s(\lambda)}{\mu_t(\lambda)}\]

Notes

  • Whenever \(\mu_s = 0\), the corresponding g value is forced to 1 and a warning is issued.

  • Array inputs can be queried at arbitrary wavelengths using the helper methods mu_s_at, mu_a_at, mu_t_at and albedo_at (linear interpolation).

Examples

dermis = Medium(
    n=1.4,
    mu_s=[15, 12, 10],          # at 600, 650, 700 nm
    mu_a=[0.30, 0.25, 0.20],
    wavelengths=np.array([600, 650, 700]),
    g=0.9,
    desc="dermis"
)

dermis.mu_t_at(650)             # 12.25 mm⁻¹
dermis.albedo_at([600, 700])    # array([0.9804, 0.9804])

class photon_canon.optics.Photon(wavelength, batch_size=10, system=None, directional_cosines=(0, 0, 1), location_coordinates=(0, 0, 0), weights=1, russian_roulette_constant=20, recurse=True, recursion_depth=0, recursion_limit=100, throw_recursion_error=True, keep_secondary_photons=False, tir_limit=inf)

Bases: object

Simulated photon (or batch of photons) for Monte-Carlo light-transport modelling.

The object tracks each photon’s wavelength, position, direction and statistical weight while it propagates through

an optical System. Built-in routines handle movement, scattering, absorption, interface interactions and Russian-roulette termination.

Variables:

  • n (int) – Number of photons in the batch.

  • wavelength (float | Iterable[float]) – Wavelength(s) in nanometres.

  • system (System) – Optical system that contains the batch.

  • directional_cosines (IndexableProperty) – Direction cosines (μ_x, μ_y, μ_z) for every photon.

  • location_coordinates (numpy.ndarray) – Cartesian coordinates (x, y, z) for every photon.

  • weights (numpy.ndarray) – Statistical weights (initially 1.0).

  • russian_roulette_constant (float) – Survival threshold for Russian-roulette.

  • recurse (bool) – Enable creation of secondary photons.

  • recursion_depth (int) – Current recursion depth.

  • recursion_limit (int) – Maximum permitted recursion depth.

  • throw_recursion_error (bool) – Raise an error (True) or just warn (False) when the limit is exceeded.

  • keep_secondary_photons (bool) – Retain secondary photons once spawned.

  • tir_limit (float) – Cosine threshold for total-internal reflection.

  • A (float) – Cumulative absorbed weight.

  • R (float) – Cumulative reflected weight (back-exit).

  • T (float) – Cumulative transmitted weight (forward-exit).

  • exit_location (numpy.ndarray) – Terminal coordinates of each photon.

  • exit_direction (numpy.ndarray) – Terminal direction cosines.

  • exit_weights (numpy.ndarray) – Terminal weights.

  • location_history (numpy.ndarray) – Complete trajectory history (steps × n × 3).

  • weights_history (numpy.ndarray) – Corresponding weight history (steps × n).

  • cache_register (numpy.ndarray) – Boolean mask—medium lookup cached?

  • at_interface (numpy.ndarray) – Boolean mask—photon currently at an interface?

Key methods

  • __init__() – construct a photon packet.

  • simulate() – propagate until all photons terminate (moves,

    absorbs, scatters, handles interfaces).

  • absorb() – deposit weight according to medium albedo.

  • move() – advance photons, handling boundary crossings.

  • reflect_refract() – deterministic update at interfaces with Fresnel/TIR handling.

  • scatter() – random direction change using phase function.

  • russian_roulette() – survival test for low-weight photons.

  • copy() – deep copy of the photon packet.

  • plot_path() – visualise trajectories in 3-D or projection.

Decrements the weights of the photon batch according to the albedo of the current medium.

If mediums is provided, the function uses it instead of re-querying system.in_mediums() to determine the current state. move(step=None)

Moves the photon one step in its current direction.

The size of the step can be either provided directly, or it can be determined by the mean free path of the current medium, which is calculated from the transport coefficient (mu_t). If the photon is in a medium with mu_t = 0 (i.e., no scattering or absorption), the photon will automatically advance to the next interface along its direction.

If a step size is provided, the photon moves in the direction specified by its directional cosines until it either completes the step or hits an interface. If the full step would cross an interface, only the portion of the step before the interface is executed. At the interface, the photon is refracted and reflected according to the media properties, and its weights is updated (decremented) based on the interaction.

Parameters:

step (float | Iterable[float], optional) – The distance the photon should move. If not provided, the step size is sampled based on the mean free path, \(-\frac{\ln\xi}{\mu_t}\)

Raises:

ValueError – If step is an array of incompatible shape.

Return type:

None

Returns:

None. The photon’s location coordinates and directions are updated.

simulate()

Simulates the behavior of a batch of photons until all photons are terminated and updates the object’s attributes accordingly.

The simulation involves the following steps: - Absorption: Photons interact with the medium and may be absorbed. (See self.absorb). - Movement: Photons move within the medium. (See self.move). - Scattering: Photons may scatter as they travel through the medium. (See self.scatter).

The exact behavior of these events depends on the optical properties of the Medium object the photon is in, which is determined through queries to the System that contains the photon, i.e., self.system.

in_medium(location)

Return the medium(s) that are at the queried coordinate. If the coordinate is an interfaces location, the mediums that makeup the interfaces are returned as a tuple, this includes boundary interfaces being returned with False on the surroundings side.

### Process 1. Get the z-coordinate from the input 2. Check it against boundaries of each medium of the system until it is found that either:

  • It is between any of the boundaries, it is in the medium within those boundaries

  • It is at a boundary, it is “in” the two mediums that make up that interfaces

  1. Break and return the medium(s) of the queried point.

Parameters:

interface_crossed(location0, location1)

Determines the first interfaces crossed when moving between two locations, considering only the z-coordinates.

This method checks if any interfaces boundaries lie between the given z-coordinates. If an interfaces is crossed, the method calculates its z-location and identifies the two mediums forming the interfaces.

### Process: 1. Identify boundaries that fall between the start and end z-coordinates. 2. Compute the distance from the start z-coordinate to each boundary. 3. Apply a mask to filter boundaries that are actually crossed. 4. Select the closest crossed boundary as the interfaces plane. 5. Determine the two mediums making up the interfaces by slightly shifting the plane’s z-coordinate:

  • Backwards (toward the start) to find the first medium.

  • Forwards (away from the start) to find the second medium.

Parameters:

  • location1 (Iterable[float]) – Starting location of the query.

  • location2 – Ending location of the query.

Return type:

Tuple[Medium | (), float | None]

Returns:

The two media forming the crossed interfaces, or an empty list [] if no interfaces is crossed and plane at which the interface is crossed or None.

Rtype interfaces:

Provides an up-to-date dictionary representation of layer boundaries.

This property dynamically constructs a dictionary mapping layer boundaries to their corresponding layers. It is useful for querying interfaces efficiently in float-time.

Returns:

A dictionary where keys are tuples representing layer boundaries (lower_bound, upper_bound), and values are the corresponding layers.
