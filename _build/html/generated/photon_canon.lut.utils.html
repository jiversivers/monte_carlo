photon_canon.lut.utils.add_simulation_result(simulation_id, mu_s, mu_a, g, depth, output)
Bulk-insert Monte-Carlo voxel results into mclut. Bulk insert protects against partial LUT addition, and limits

I/O time, however, this can easily be looped to write single rows at a time.

Scalars are broadcast to match iterable inputs; all iterable arguments must share the same length.

Parameters:

  • simulation_id (int) – Simulation to which the rows belong.

  • mu_s (Real | Iterable[Real]) – Scattering coefficient(s) \(\mu_s\).

  • mu_a (Real | Iterable[Real]) – Absorption coefficient(s) \(\mu_a\).

  • g (Real | Iterable[Real]) – Anisotropy factor(s) g.

  • depth (Real | Iterable[Real]) – Depth coordinate(s) where output was recorded.

  • output (Real | Iterable[Real]) – Recorded quantity (e.g. reflectance).

Raises:

ValueError – If iterable arguments have mismatched lengths.

Returns:

None – rows are committed to the database.

Return type:

None

photon_canon.lut.utils.add_system_data(simulation_id, system)

Persist the optical-system stack for a given simulation_id.

One row per layer is written to fixed_layers; thickness and optical properties are frozen at the layer’s reference wavelength.

Parameters:

  • simulation_id (int) – Foreign-key referencing mclut_simulations.id.

  • system (System) – The System whose layers are recorded.
