Generate a synthetic absorbance spectrum for an arbitrary mixture of food-coloring dyes (or their premixed stocks) by linear super- position of reference spectra.
photon_canon.contrib.food_coloring.make_mix(wavelengths=None, *, red=0, yellow=0, green=0, blue=0, stock_a=0, stock_b=0)

Generate a synthetic absorbance spectrum for an arbitrary mixture of food-coloring dyes (or their premixed stocks) by linear super- position of reference spectra.

Parameters

type wavelengths:

ndarray

param wavelengths:

1-D array of wavelengths \(\lambda\;[\text{nm}]\) at which the spectrum should be returned. If None (default), the function returns values on the native sampling grid contained in the reference files.

type wavelengths:

ndarray, optional

type red:

float

param red:

Concentrations (in µL dye / mL solution) of the red stock dyes to mix. Keyword only.

type red:

float, optional

type yellow:

float

param yellow:

Concentrations (in µL dye / mL solution) of the yello stock dyes to mix. Keyword only.

type yellow:

float, optional

type green:

float

param green:

Concentrations (in µL dye / mL solution) of the green stock dyes to mix. Keyword only.

type green:

float, optional

type blue:

float

param blue:

Concentrations (in µL dye / mL solution) of the blue stock dyes to mix. Keyword only.

type blue:

float, optional

type stock_a:

float

param stock_a:

Concentrations (µL/mL) of premixed Stock A to mix. Keyword only.

type stock_a:

float, optional

type stock_b:

float

param stock_b:

Concentrations (µL/mL) of premixed Stock B to mix. Keyword only.

type stock_b:

float, optional

  • \(\text{Stock A}=0.125\,\text{mL/mL red} + 0.175\,\text{mL/mL green}\)

  • \(\text{Stock B}=0.600\,\text{mL/mL yellow} + 0.050\,\text{mL/mL blue}\)

Returns

return:

Absorbance spectrum \(A(\lambda)\) with the same length and ordering as wavelengths (or the native grid).

rtype:

np.ndarray[float]

Notes

The mixture obeys the Beer–Lambert law, so absorbances add linearly:

\[A(\lambda) \;=\; \sum_{i} c_i\,a_i(\lambda),\]

where

  • \(a_i(\lambda)\) is the per-unit absorbance spectrum of dye i (1 µL / mL reference), and

  • \(c_i\) is the requested concentration (µL/mL).

The premixed stocks are treated exactly the same way, using their own per-unit spectra.

Examples

>>> # 0.2 µL/mL red + 0.1 µL/mL blue
>>> A = make_mix(red=0.2, blue=0.1)
>>> A.shape
(401,)
>>> # Integrated optical density between 400–700 nm
>>> wl = np.linspace(400, 700, 301)
>>> A_int = np.trapz(make_mix(wl, stock_a=0.05), wl)
>>> A_int
12.3
